# Third-party runtime

The runtime/python directory is the unmodified set of top-level files from the CPython 3.12 Windows embeddable runtime already included with the control-station delivery, except python312._pth only enables the bundled standard library and current runtime directory. The original LICENSE.txt is retained alongside the binaries. No system installation or global Python settings are changed.

Other software and model licenses remain in their original delivery archives.
