# 当前算法与 V8 结构：多工况仿真及实拍对照

整理日期：2026-11-09。本次实际执行78组：6条轨迹 × 11种环境条件 = 66组，另对3条轨迹的名义条件和掉帧条件各增加2个随机种子，共12组重复。全部运行完成，运行检查无失败；这不是78次物理捕获成功。

## 本次做了什么

复用当前 v31.2 的 LedPairObserver、LedVisionStream._process、近似双灯三维观测、FlightArcRoute、接收平面控制、有限 MOVE_J 参考、安全门和关圈状态机。只将硬件相机、CAN执行器及光圈反馈换成仿真适配器。图像先生成像素，再走实际检测器；控制器没有读取合成轨迹真值。

保存当前源码快照与来源 SHA256，不连接机械臂、相机或串口。源项目的算法和设备参数未修改。

## 条件矩阵

| 执行器变慢 | 60 ms指令延迟、2 rad/s²加速度；名义值为20 ms、5 rad/s² |

| 安装偏差 | 相机平移8.7 mm、转角0.24°；借用留出标定解变化量作敏感性幅度，并非误差置信区间 |
| 斜视 | 灯杆绕初始相机竖直轴旋转20°，保留真实0.35 m长度；引入不等深偏差 |

轨迹包括0.6/1.2 m/s直线、12 cm侧偏、10 cm弯曲来向，以及最后两次实拍条件重建。解析轨迹在0.7 s静止后开始接近，灯对中点最接近预设约0.28 m；未人为制造接触或夹持成功。

## 当前结构和相机

使用官方六轴 PiPER URDF及网格，V8含紧固件定义为76组件、17个零件类型。显示时R02固定外壳与R03输出盘由官方机器人网格承担，避免重复绘制；其余74个机构组件由原BREP生成网格。35°前导引板候选没有合入本次V8显示。

控制与碰撞门沿用当前生产配置；生产碰撞包本来采用70个机构包络。新显示网格中的紧固件没有被误当成新实测碰撞模型。

相机内参 fx=415.945279、fy=417.732147、cx=328.367592、cy=232.040874，分辨率640×480，采用现有五项畸变和T_tcp_camera。控制频率目标120 Hz，曝光目标60 Hz；本仿真使用离散事件与确定性工作预算，不是操作系统实时调度性能测试。

机械安装仍有一个必须保留的证据边界：当前算法配置的近似筒轴与名义CAD筒轴在TCP坐标下相差约47.264°。这反映两套尚未统一实测的安装定义，不能直接解释成实物装错47°。三维显示保留V8各零件几何，用刚性变换把筒口放到当前控制使用的近似接收平面，并明确标作安装示意。该变换只用于显示，不改控制或碰撞配置。要做结构接触仿真，必须先完成筒口中心、筒轴和法兰时钟方向的统一实测。

光圈显示使用现有CAD凸轮几何，按预收875、前1450、后1250及示意线性舵机位置—角度关系展示。前圈到1450的约0.876 s沿用空行程比例估计；后圈875→1250约0.567 s有空行程到位计时依据。两者都不是接触时间或夹持力。

## 计算口径

双灯等深观测：去畸变得到两条归一化射线，令共同深度 z = 0.35 / ||r1_xy-r2_xy||，再用曝光时刻的关节姿态与手眼矩阵转换到基坐标。输出是灯对中点。斜视时该等深假设会出现尺度偏差，不能获得飞机完整6D姿态。

执行器模型：速度受3 rad/s上限约束，目标速度按剩余距离及制动距离生成，速度变化限于指定加速度，MOVE_J经显式延迟后生效。它是运动学和有限速度/加速度执行器模型，没有求解完整关节力矩、柔性、摩擦、真实重力补偿或冲击。

每个时刻的轴线侧向偏差定义为 e=||d-a(aᵀd)||，d为仿真灯对中点减当前接收平面中心，a为当前筒轴。它是相对一条轴线的几何误差，不能换算成飞机机头入筒裕量。表中同时提供全轨迹P95与轴向距离0–0.8 m子区间P95；不同条件的近场样本数量也保留，防止将样本缺失误认为性能提高。

1.2 m/s直线条件下，100 ms延迟和降帧/掉帧条件相较名义条件有更大的全轨迹轴线误差。侧偏与弯曲轨迹出现显著误差，且变化不总是随延迟单调。不能只挑直线算例推断全工况鲁棒性。

180 ms延迟的6组运行均没有TRACKING_3D、没有关圈、没有关节净位移。统计中1条MOVE_J是初始保持命令，不能写成发生了追踪。图像检测器仍可能检出灯对，因此“灯对可见率”与“图像能被控制器采用”是不同量。

这些时间比较使用最后两次成片对应记录中、关圈之前约3 s的可重建窗口。重建轨迹复用了同一等深双灯假设及记录关节值，故不是独立三维真值，也没有测得仿真到实物的定位精度。原成片是事件对齐，外部与机载画面的估计对齐误差约±50 ms；记录曝光时刻还有既有时间估计不确定性，5 ms表面接近不能单独证明高精度迁移。

11月9日片段帧龄中位约96 ms，明显超过40 ms名义条件。100 ms+抖动算例的关圈时刻为2.725 s，相对实录约晚67 ms；这可作为时序差距的敏感性证据，不是重新拟合后的预测精度证明。所有条件原始结果一起提供。

相机图像只用程序生成的背景、边缘、光晕、像素噪声和模糊；没有复刻现场光照、真实背景纹理、自动曝光、滚动快门及严重镜头炫光。实拍与仿真的灯对可见比例分母不同，报告没有把两者相减当作检测性能提升。

## 可以怎样用于论文

可以支持：同一生产算法在合成像素输入下完整闭环运行；相机内参、手眼、名义机构、控制频率、舵机时序、运行数据来源均可追溯；对时序、成像和执行器扰动给出可复现敏感性算例；两次记录给出案例级时序对照和失败模式。

尚不能支持：实物捕获成功率、接触力/夹持力/耗能、学习策略迁移成功、完整真实域分布、独立精确6D定位或对未见工况的一般化。这里没有进行强化学习或域随机化训练，也不把本次固定参数扫描称为新的sim-to-real算法。

建议文章把这批结果放在“工程一致性与敏感性验证”或“仿真—实机过程对照”部分，保留偏置/曲线失败算例及未实测参数表。若要升级为物理捕获验证，下一步需要独立运动真值、统一筒口标定、舵机角度/开口映射、带载闭合及接触试验。
